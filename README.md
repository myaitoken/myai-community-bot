# MyAI Network Community Bot

Official Telegram community bot for the MyAI Network TGE.

**Bot:** [@MyAI_Token_bot](https://t.me/MyAI_Token_bot)
**Channel:** [@MyAITokenNews](https://t.me/MyAITokenNews)
**Website:** [myaitoken.io](https://myaitoken.io)

## Features
- Live TGE countdown + liquidity lock status
- Genesis Window tracker (100 slots, referral system)
- Wallet setup guide (Base/MetaMask)
- Agent-friendly JSON endpoints
- Anti-spam moderation + admin commands
- SQLite analytics DB

## Commands
`/start` `/tge` `/marketplace` `/wallet` `/buy` `/refer` `/network`
`/docs` `/contract` `/invest` `/status` `/rules` `/help`
`/status_json` `/network_stats` `/get_compute`

## Deploy
```bash
pip install python-telegram-bot aiohttp
cp .env.example .env
python myai_community_bot.py
```
